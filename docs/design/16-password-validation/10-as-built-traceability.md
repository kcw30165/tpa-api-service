# 10 As-built traceability

This maps the requirements R01 to R20 in [05 Test and traceability](05-test-and-traceability.md) to the tests that exist in the repository at the end of M5. It does not replace document 05, which describes the planned acceptance criteria.

**Evidence basis.** Every test method named below was checked against the per-test results recorded by evidence script 051 for the final full-suite run at commit `96eaacd4`, and has a passing status there (1,325 report files, 7,234 tests, 0 failures, 0 errors, 10 skipped; the skipped tests are unrelated to this feature). The Redis-backed classes (`AuthenticatedSessionConditionalWriteRedisTest`, `PasswordValidationTokenGateHttpTest`) run only when `-Dm15.redis.server` is set. A plain `mvn test` skips them, so keep the property in every gate.

**Not executed anywhere:** a real browser, a live `TRPPwdValidation` call, deployed Redis, deployed CORS values, and the ingress or gateway logging. See document 09, section 7.

Test names are abbreviated as `Class.method`; a method listed once may be parameterised.
